# qArt-code

> A fully decentralized, customizable, and client-side QR Code Studio built for **Artizens**.

![qArt-code Preview](./qArt-code.jpeg)

---

## 🌟 Overview

**qArt-code** is an open-source, serverless web application that allows creators to generate highly styled, brandable QR codes. Designed specifically to run seamlessly on static hosting, local environments, and decentralized storage networks like **IPFS**, qArt-code gives you granular control over shapes, color palettes, and embedded center logos without relying on centralized APIs or third-party shorteners.

---

## ✨ Features

- **Decentralized & Serverless:** 100% client-side execution. Runs locally off disk or pinned directly to an IPFS gateway.
- **Custom Logo Integration:** Defaults to the dWeb Artizen logo while supporting local image file uploads (`Base64`) to bypass CORS security constraints.
- **Granular Stylization Controls:**
  - **Body Modules:** Custom dot patterns (*Extra Rounded, Dots, Rounded, Classy, Square*).
  - **Corner Alignment:** Independent styling and coloring for both outer frames and inner eye patterns.
- **Smart Quality Guardrails:**
  - **Color Contrast Checker:** Real-time WCAG contrast warnings to ensure high readability across mobile camera sensors.
  - **Payload Density Alerts:** Automatic UI notifications when URLs exceed character limits to help keep QR matrices scannable.
- **Multi-Format Export:** Instant downloads for both web-ready **PNG** and scalable vector **SVG** (ideal for print, stickers, and physical art pieces).
